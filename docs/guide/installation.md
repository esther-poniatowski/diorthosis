# Installation

Diorthosis installs into the plugin folder of a vault. No release is published yet, so the plugin can be installed from the source code only.

## Prerequisites

The plugin requires Obsidian 1.6.6 or later. Building it requires the Node version fixed by the version file `.nvmrc` of the repository.

## Installation from source

To use the plugin, the user builds the bundle from the source code and links it into a vault, following the [development setup](../../CONTRIBUTING.md). Once the bundle is built, the user enables *Diorthosis* in *Settings → Community plugins*.
